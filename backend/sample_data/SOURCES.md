# Sample datasets

All bundled datasets are public domain or CC0, so they can be redistributed with this repository.
They were taken from two openly licensed Python packages on PyPI (data files only):
`vega_datasets` 0.9.0 (BSD-3-Clause; data from the sources below) and `palmerpenguins` 0.1.6.

| File | Rows | Source | Licence | Changes |
|---|---|---|---|---|
| `ecommerce_orders.csv` | 18,861 | Synthetic, generated by `generate_ecommerce.py` (not committed; created on first use) | MIT (this repository) | — |
| `seattle_weather.csv` | 1,461 | NOAA Global Historical Climatology Network (GHCN-Daily), Seattle, 2012–2015, via vega-datasets | Public domain (US government work) | dates rewritten from `2012/01/01` to ISO `2012-01-01` |
| `us_employment.csv` | 120 | US Bureau of Labor Statistics, Current Employment Statistics, monthly 2006–2015 (thousands of jobs), via vega-datasets | Public domain (US government work) | column `month` renamed `date` (a reserved word in SQL); the source's `trade_transportation_utilties` spelling is kept |
| `iowa_electricity.csv` | 51 | US Energy Information Administration, net generation in Iowa by source, 2001–2017 (thousand MWh), via vega-datasets | Public domain (US government work) | columns `year` → `date` and `source` → `energy_source` (reserved words in SQL) |
| `palmer_penguins.csv` | 344 | Gorman KB, Williams TD, Fraser WR (2014). *Ecological sexual dimorphism and environmental variability within a community of Antarctic penguins (genus Pygoscelis).* PLoS ONE 9(3): e90081. Palmer Station Antarctica LTER, via the palmerpenguins package (Horst, Hill & Gorman, 2020) | CC0 1.0 | missing values written as empty fields instead of `NA` (19 cells); column `year` → `study_year` |

`catalog.json` lists the datasets shown in the app, with example questions for each.
